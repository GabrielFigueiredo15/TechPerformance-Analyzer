# TechPerformance-Analyzer-An-lise-de-Desempenho-de-Computadores-com-Correla-o-e-Regress-o-Linear
Projeto de Métodos Quantitativos que analisa fatores técnicos de computadores, como memória, cache e tempo de ciclo, para prever o desempenho relativo usando correlação e regressão linear múltipla em Python.
